# Курс: Процесс Грама–Шмидта с абсолютного нуля

Этот курс написан для человека, который:

- **не знает программирования вообще**;
- **имеет пробелы в школьной математике**;
- хочет в итоге **уверенно понимать процесс Грама–Шмидта** (Gram–Schmidt)
  и быть готовым перейти к собственным векторам (eigenvectors).

Каждый урок объясняет **каждую строку и каждое действие**. Ничего не считается
«очевидным». Если что-то кажется слишком простым — отлично, просто читай дальше быстрее.

**Как открыть ноутбук (без установки чего-либо):**

1. Зайди на `https://colab.research.google.com` (нужен аккаунт Google).
2. Меню *Файл → Загрузить блокнот* (File → Upload notebook).
3. Выбери скачанный `.ipynb`-файл — и запускай ячейки по Shift+Enter.

В каждом задании замени `...` на свой ответ — встроенный проверяльщик
сразу скажет ✅ или ❌. Решения спрятаны под спойлерами «👉 Нажми сюда».

Папка `igra/` — **играбельная игра «ВЕКТОР: Ортонорма»**: открой

до `T = E·TE·Eᵀ`, три звезды за уровень, журнал формул, бесконечный
режим-тренажёр после кампании. Дизайн-документ — `igra/GAME_DESIGN.md`.

| Уровень игры | Идея | К урокам |
|---|---|---|
| 1. Ангар | вектор = направление + длина | 02 |
| 2–3. Реакторная, Калибровочная | длина, нормализация | 01, 03 |
| 4. Сенсорная | скалярное произведение, перпендикулярность | 03 |
| 5–6. Прожекторная, Мастерская | тень и её вычитание | 04 |
| 7–8. Гироскопная | Грам–Шмидт + ловушка с зависимым вектором | 07–09 |
| 9. Зеркальный отсек | простое отражение TE | 06, 10 |
| 10. Мостик | конвейер Eᵀ → TE → E | 10 |
| 11. Ядро | собери код `T = E @ TE @ E.T` | 08–10 |
