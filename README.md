# Курс: Процесс Грама–Шмидта с абсолютного нуля

Этот курс написан для человека, который:

- **не знает программирования вообще**;
- **имеет пробелы в школьной математике**;
- хочет в итоге **уверенно понимать процесс Грама–Шмидта** (Gram–Schmidt)
  и быть готовым перейти к собственным векторам (eigenvectors).

Каждый урок объясняет **каждую строку и каждое действие**. Ничего не считается
«очевидным». Если что-то кажется слишком простым — отлично, просто читай дальше быстрее.

Папка `igra/` — **игра «ВЕКТОР: Ортонорма»**: открой `igra/index.html`
в браузере (ничего устанавливать не нужно; есть однофайловая версия
`igra_odnim_failom.html`). Здесь математика — это физика мира:
**кораблём управляешь векторами тяги**, топливо тратится ровно на длину
вектора, зеркала отражают лазер настоящей матрицей каждый кадр,
тень становится мостом, а сломанный базис искажает весь сектор,
пока не починишь его Грамом–Шмидтом. Три звезды за сектор, журнал формул,
бесконечный режим. Дизайн-документ — `igra/GAME_DESIGN.md`.

| Сектор | Механика | Идея | К урокам |
|---|---|---|---|
| 0. Первая тяга | тяни вектор — корабль летит по нему | вектор = направление + длина | 02 |
| 1. Цена длины | топлива хватает только на прямой путь | длина, Пифагор | 01, 03 |
| 2. Обход астероида | маршрут из двух векторов, итог = сумма | сложение векторов | 02 |
| 3. Стыковочный импульс | док принимает только импульс длиной 1 | нормализация | 03 |
| 4. Мост из света | тень балки на рельсу = физический мост | проекция | 04 |
| 5. Перпендикулярный канал | сквозь поле можно лететь только ⊥ | разложение: тень + перпендикуляр | 04 |
| 6–7. Зеркальный луч | вращай зеркала, луч отражается матрицей | отражение, композиция | 06, 10 |
| 8. Сломанный сектор | весь мир перекошен кривым базисом — почини его | Грам–Шмидт, ортонормированный базис | 07–09 |
| 9. Зеркальный щит | собери программу щита из блоков Eᵀ→TE→E | смена базиса, `T = E @ TE @ E.T` | 10 |
