# Урок 12. Мост к собственным векторам (eigenvectors)

Цель урока: показать, что следующая большая тема — собственные векторы —
строится из идей, которыми ты УЖЕ владеешь. Это не полный урок по
eigenvectors, а трамплин: после него первая лекция о них не будет пугать.

---

## 1. Вспомним, что ты теперь умеешь

За курс сложилась цепочка:

```
вектор → длина → скалярное произведение → проекция (тень)
   → Грам–Шмидт → ортонормированный базис
   → смена базиса → «перевести, сделать простое, перевести обратно»
```

Последний пункт — формула из урока 10:

```
T = E @ TE @ E.T
```

«В удобной системе координат сложная операция становится простой».
Для зеркала удобная система — та, где одна ось лежит вдоль зеркала.

Собственные векторы отвечают на следующий логичный вопрос:

> **А как найти удобную систему координат для ЛЮБОЙ матрицы?**

---

## 2. Что делает матрица с векторами (наблюдение)

Матрица — «машинка», превращающая векторы (урок 06). Обычно она вектор
и поворачивает, и растягивает. Запусти:

```python
import numpy as np

A = np.array([[2, 1],
              [0, 3]], dtype=np.float64)

print(A @ np.array([1., 5.]))   # [ 7. 15.] — и повернуло, и растянуло
print(A @ np.array([2., 1.]))   # [ 5.  3.] — тоже повернуло
print(A @ np.array([1., 0.]))   # [ 2.  0.] — ого! направление ТО ЖЕ, длина ×2
print(A @ np.array([1., 1.]))   # [ 3.  3.] — снова то же направление, длина ×3
```

Смотри на последние две строки. Большинство векторов машинка сворачивает
куда-то вбок. Но есть ОСОБЫЕ направления, которые она **не поворачивает** —
только растягивает:

- `[1, 0]` остался на своей прямой, растянулся в 2 раза;
- `[1, 1]` остался на своей прямой, растянулся в 3 раза.

---

## 3. Определение (теперь оно очевидно)

> **Собственный вектор** (eigenvector) матрицы — это вектор, который матрица
> не поворачивает, а только растягивает (или сжимает, или разворачивает назад).
>
> **Собственное число** (eigenvalue) — во сколько раз растянула.

На языке формул:

```
A @ v = λ × v
```

где `λ` (лямбда) — то самое число. В примере выше: у `[1, 0]` λ = 2,
у `[1, 1]` λ = 3.

Каждый символ этой формулы ты знаешь: `A @ v` — матрица действует на вектор
(урок 06), `λ × v` — умножение вектора на число (урок 02). Формула говорит:
«результат машинки = просто растянутый исходник».

Слово «eigen» — немецкое, означает «собственный/свой»: у каждой матрицы
СВОИ особые направления, это её личный характер.

---

## 4. Зачем они нужны (та же схема, что с зеркалом!)

В уроке 10 удобным базисом для зеркала были оси «вдоль + поперёк зеркала»,
и в них отражение стало тривиальной матрицей `[[1, 0], [0, -1]]`.

Для произвольной матрицы A удобный базис — её **собственные векторы**.
Если перейти в их систему координат, машинка A превращается в простейшую:

```
D = [[λ1, 0],
     [0, λ2]]        — только растяжения по осям, никаких поворотов!
```

И формула перехода — та же самая, что у зеркала:

```
A = C @ D @ C⁻¹
```

где в столбцах `C` стоят собственные векторы (сравни: `T = E @ TE @ E.T`).
Читается справа налево, как учил урок 10: перевести в удобный базис →
растянуть по осям → перевести обратно.

Кстати, вот и место встречи с Грамом–Шмидтом: у «хороших» (симметричных)
матриц собственные векторы перпендикулярны, их можно нормализовать —
и тогда `C⁻¹ = C.T`, как в уроке 10. А для «кривых» наборов векторов
Грам–Шмидт и численные методы на его основе наводят порядок.

Зачем это на практике: возвести матрицу в сотую степень (процессы во времени),
Google PageRank, колебания мостов, сжатие данных, квантовая механика — всюду
первым делом ищут собственные векторы, чтобы работать в удобном базисе.

## 5. Потрогай руками (NumPy умеет находить их сам)

```python
import numpy as np
import numpy.linalg as la

A = np.array([[2, 1],
              [0, 3]], dtype=np.float64)

lam, C = la.eig(A)        # eig = найди eigenvalues и eigenvectors
print("собственные числа:", lam)      # [2. 3.]
print("собственные векторы (по столбцам!):")
print(C)
```

Разбор:

- `la.eig(A)` возвращает СРАЗУ ДВЕ вещи: список собственных чисел и матрицу,
  в столбцах которой — собственные векторы (нормализованные, длины 1 —
  привет, урок 03!).
- `lam, C = ...` — двойное присваивание: первая вещь в `lam`, вторая в `C`.
- Векторы, как всегда в этом курсе, — по столбцам: `C[:, 0]`, `C[:, 1]`.

Проверь определение сам (лучшее упражнение):

```python
v = C[:, 0]
print(A @ v)          # машинка подействовала...
print(lam[0] * v)     # ...и это то же самое, что растяжение! Совпадут.
```

## 6. Что учить дальше (порядок имеет значение)

1. **Определение через картинку**: какие направления матрица не поворачивает.
   (Ты уже понял это в разделе 2.)
2. **Как находить руками** в 2D: характеристическое уравнение
   `det(A - λI) = 0`. Единственный по-настоящему новый инструмент —
   определитель (det); всё остальное у тебя есть.
3. **Диагонализация** `A = C @ D @ C⁻¹` — ты уже знаешь этот узор из урока 10.
4. **Симметричные матрицы**: собственные векторы перпендикулярны — тут снова
   всплывут ортонормированные базисы и Грам–Шмидт.

Совет: проходя лекции про eigenvectors, каждый раз спрашивай себя —
«где здесь смена базиса? где здесь "перевести → сделать простое → вернуться"?»
Ответ будет находиться всегда, и тема ляжет на подготовленную почву.
