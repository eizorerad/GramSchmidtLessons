## 1. Из чего состоит курс

Курс — это набор текстовых файлов (уроков) и несколько файлов с кодом на языке Python.

- Файлы `.md` — это уроки. Их читаешь.
- Файлы `.py` — это программы. Их запускаешь и меняешь.

Читать без запуска кода — почти бесполезно. Вся сила курса в том,
что ты **меняешь числа и смотришь, что получилось**.

## 2. Где запускать код (3 варианта, выбери один)

### Вариант А. Google Colab — самый простой, ничего не надо устанавливать

1. Открой в браузере сайт: `https://colab.research.google.com`
2. Войди с аккаунтом Google.
3. Нажми «New Notebook» (Новый блокнот).
4. Появится пустая ячейка — это окошко, куда пишут код.
5. Скопируй туда код из урока.
6. Нажми на кнопку ▶ слева от ячейки (или клавиши Shift+Enter).
7. Под ячейкой появится результат.

Всё. Больше ничего не нужно. Библиотека NumPy (мы будем её использовать)
там уже установлена.

### Вариант Б. Сайт-песочница

Открой `https://www.online-python.com` или похожий сайт «Python online».
Вставь код, нажми Run. Минус: не на всех таких сайтах есть NumPy.
Если пишет ошибку `No module named numpy` — используй вариант А.

### Вариант В. Установить Python на свой компьютер

1. Скачай Python с сайта `https://python.org` и установи.
2. Открой терминал (командную строку) и набери: `pip install numpy`
3. Сохрани код в файл, например `test.py`.
4. Запусти командой: `python test.py`

Если это звучит страшно — не мучайся, используй вариант А (Colab).

## 3. Твоя первая программа (проверка, что всё работает)

Скопируй это и запусти:

```python
print("Привет! Всё работает.")
```

Разбор этой строки:

- `print` — команда «напечатай на экран». Это самая частая команда в обучении:
  она показывает нам, что происходит внутри программы.
- Круглые скобки `()` — в них кладут то, что нужно напечатать.
- Кавычки `"..."` — так обозначают текст. Без кавычек Python подумает,
  что это имя какой-то переменной, и выдаст ошибку.

Если на экране появилось `Привет! Всё работает.` — ты готов.

## 4. Проверим, что работает NumPy

NumPy — это дополнение к Python для работы с векторами и матрицами.
Про него будет целый урок (06), а сейчас просто проверим:

```python
import numpy as np
print(np.array([1, 2, 3]))
```

Разбор:

- `import numpy as np` — «подключи библиотеку numpy и дай ей короткое имя np».
  Это как сохранить длинный номер телефона под коротким именем в контактах.
- `np.array([1, 2, 3])` — «сделай из списка чисел 1, 2, 3 вектор».
- `print(...)` — покажи результат.

Должно напечататься: `[1 2 3]`

## 5. Как проходить уроки

Правила простые:

1. **Один урок за один подход.** Не глотай по три урока — не уляжется.
2. **Каждый кусок кода запускай.** Даже если «и так понятно».
3. **После запуска поменяй числа и запусти ещё раз.** Угадай результат заранее,
   потом проверь. Угадал — понял. Не угадал — перечитай объяснение.
4. **Мини-задачи в конце урока — обязательны.** Ответы даны, но сначала попробуй сам.
5. Застрял — вернись на урок назад. Это не поражение, это и есть учёба.

## 6. Что делать при ошибке в коде

Ошибки — это нормально. Ошибка не значит «сломал», значит «Python не понял».

Самые частые:

| Ошибка на экране | Что это значит | Что делать |
|---|---|---|
| `SyntaxError` | опечатка: забыл скобку, кавычку, двоеточие | сравни свой код с уроком символ в символ |
| `NameError: name 'x' is not defined` | используешь имя, которое ещё не создал | проверь, что строка с `x = ...` есть ВЫШЕ |
| `No module named numpy` | нет библиотеки NumPy | используй Google Colab |
| `IndentationError` | неправильные отступы (пробелы в начале строки) | внутри функций отступ 4 пробела |
