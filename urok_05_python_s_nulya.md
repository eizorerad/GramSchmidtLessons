## 1. Переменные: коробки с именами

```python
x = 5
```

Это НЕ уравнение. Знак `=` в Python означает: **«положи в коробку с именем x число 5»**.

```python
x = 5          # в коробке x лежит 5
y = x + 2      # взяли из коробки x (там 5), прибавили 2, положили 7 в коробку y
x = 10         # ВЫБРОСИЛИ старое содержимое, теперь в x лежит 10
print(y)       # напечатает 7 — y уже посчитан раньше и не меняется сам по себе
```

Важно: программа выполняется **сверху вниз, строка за строкой**.
Каждая строка — одно действие.

Имена коробок могут быть любыми словами: `x`, `dlina`, `verySmallNumber`.
Заглавные/строчные буквы различаются: `B` и `b` — разные коробки.

## 2. print: посмотреть, что внутри

```python
v = 42
print(v)             # напечатает: 42
print("привет")      # напечатает: привет
print("v =", v)      # напечатает: v = 42
```

- Текст пишется в кавычках. Без кавычек — это имя переменной.
- Через запятую можно печатать несколько вещей — они выведутся через пробел.

`print` — твой главный инструмент. Не понимаешь, что в переменной? Напечатай её!

## 3. Списки: несколько чисел в одной коробке

```python
spisok = [10, 20, 30]
```

Квадратные скобки — список. Элементы нумеруются **С НУЛЯ**:

```python
print(spisok[0])    # 10 — НУЛЕВОЙ элемент (первый по-человечески)
print(spisok[1])    # 20
print(spisok[2])    # 30
```

Почему с нуля? Историческая традиция программирования. Просто прими:
**«номер 0» = «первый»**. В матрицах будет так же: столбец номер 0 —
это первый столбец.

## 5. Функции: рецепты с именем

Функция — это кусок кода, которому дали имя, чтобы вызывать его много раз.

```python
def udvoit(chislo):          # определяем функцию с именем udvoit
    rezultat = chislo * 2    #     тело функции (с отступом!)
    return rezultat          #     вернуть ответ тому, кто спросил

print(udvoit(5))             # 10
print(udvoit(100))           # 200
```

Разбор по словам:

- `def` — «определяю функцию» (define).
- `udvoit` — имя, которое мы придумали.
- `(chislo)` — **параметр**: коробка, куда положат то, что нам передадут.
  Вызвали `udvoit(5)` — в коробке `chislo` оказалось 5.
- `:` — двоеточие обязательно, оно означает «дальше идёт тело».
- **Отступ в 4 пробела** — так Python понимает, какие строки принадлежат
  функции. Отступ — это не красота, это грамматика языка!
- `return` — «вот ответ, я закончила». Ответ прыгает туда, откуда функцию вызвали:
  `udvoit(5)` превращается в `10`.

В курсе будет функция `gsBasis(A)`: «дай мне матрицу A — верну её
ортонормированную версию». Теперь ты знаешь, как читать её заголовок.

## 6. if/else: развилка

```python
dlina = 0.00000000001

if dlina > 0.0000001:            # ЕСЛИ условие верно...
    print("вектор настоящий")    #     делаем это
else:                            # ИНАЧЕ...
    print("вектор почти ноль")   #     делаем вот это
```

- После `if` пишется условие. `>` больше, `<` меньше, `==` равно
  (два знака! один `=` — это «положи в коробку»).
- Снова двоеточие и отступ — тело развилки.
- Выполнится РОВНО ОДНА из веток.

В Грам–Шмидте `if` нужен ровно в одном месте: «если от вектора после вычитания
теней осталось что-то заметное — нормализуем; иначе — записываем ноль».

## 7. Цикл for: повторить много раз

```python
for i in range(4):
    print("шаг номер", i)
```

Напечатает:

```
шаг номер 0
шаг номер 1
шаг номер 2
шаг номер 3
```

Разбор:

- `range(4)` — последовательность чисел `0, 1, 2, 3` (четыре числа, с нуля!).
- `for i in range(4):` — «повтори тело 4 раза; на каждом повторе клади
  очередное число в коробку i».
- Тело цикла — строки с отступом.

Ещё нам встретится `range(j)` — числа от 0 до `j-1`. Если `j = 2`,
то это `0, 1`. И цикл в цикле:

```python
for j in range(3):           # j будет 0, 1, 2
    for i in range(j):       # i пробегает всё, что МЕНЬШЕ j
        print("j =", j, "i =", i)
```

Напечатает:

```
j = 1 i = 0
j = 2 i = 0
j = 2 i = 1
```

Заметь: при `j = 0` внутренний цикл не выполнился ни разу (`range(0)` — пусто).
Смысл конструкции: **«для каждого следующего вектора j пройдись по всем
предыдущим i»**. Это ровно то, что делает Грам–Шмидт: из вектора номер j
вычитаются тени на ВСЕ предыдущие векторы. Запомни этот узор.

## 8. import: подключение библиотек

```python
import numpy as np
import numpy.linalg as la
```

- `import numpy` — «подключи библиотеку numpy» (коробка с готовыми инструментами
  для векторов и матриц).
- `as np` — «буду звать её коротко: np».
- `numpy.linalg` — раздел numpy с линейной алгеброй (там живёт `norm` — длина).

После этого пишем `np.array(...)`, `np.sqrt(...)`, `la.norm(...)` —
«инструмент такой-то из коробки такой-то».

## 9. Читаем «страшную» строку целиком

Вот строка из будущего урока 08:

```python
B[:, 1] = B[:, 1] - B[:, 1] @ B[:, 0] * B[:, 0]
```

Пока не пугайся `B[:, 1]` — это «столбец номер 1 матрицы B» (следующий урок).
Смотри на СТРУКТУРУ, она тебе уже знакома:

```
что-то = что-то - (что-то @ что-то) * что-то
   ↑        ↑         ↑                ↑
 положи   вектор   скалярное        умножить на
 в коробку          произведение    вектор = ТЕНЬ
```

Это формула из урока 04: `v - (v · e) × e` — «вычесть тень»!
Код курса — это три формулы из уроков 03–04, обёрнутые в переменные,
функции и циклы из этого урока. Ничего больше.

## 10. Мини-задачи

Предскажи вывод КАЖДОЙ программы до запуска, потом запусти и проверь.

1.
```python
a = 3
b = a * 2
a = 100
print(b)
```

2.
```python
s = [5, 10, 15]
print(s[1])
```

3.
```python
def plus_odin(x):
    return x + 1

print(plus_odin(plus_odin(10)))
```

4.
```python
for i in range(3):
    print(i * 10)
```

5.
```python
x = 7
if x > 10:
    print("большой")
else:
    print("маленький")
```

---

## Ответы

1. `6` — b посчитан, когда a было 3; дальнейшая замена a на b не влияет.
2. `10` — номер 1 значит ВТОРОЙ элемент (счёт с нуля).
3. `12` — внутренний вызов дал 11, внешний прибавил ещё 1.
4. `0`, `10`, `20` — i пробегает 0, 1, 2.
5. `маленький` — 7 не больше 10, выполнилась ветка else.
