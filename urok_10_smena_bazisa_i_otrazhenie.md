# Урок 10. Смена базиса и отражение (задача «медведь и зеркало»)

Цель урока: применить Грам–Шмидт к настоящей задаче — отразить точку
в наклонном зеркале. Заодно освоить **смену базиса** — одну из самых важных
идей линейной алгебры (и главный мостик к собственным векторам).

Это самый сложный урок курса. Читай медленно, запускай каждый кусок кода.

---

## 1. История задачи

Медведь смотрит в зеркало. Зеркало стоит НАКЛОННО — не вдоль оси x и не вдоль
оси y, а как попало. Вопрос: **где окажется отражение точки?**

Если бы зеркало лежало ровно вдоль оси x, всё было бы просто:

```
(x, y) → (x, -y)     — «вдоль зеркала не меняем, поперёк — переворачиваем»
```

В коде эта простая машинка выглядит как матрица (урок 06, раздел 6):

```python
TE = np.array([[1, 0],
               [0, -1]])
# TE @ [2, 3] даст [2, -3] — отражение относительно оси x
```

Но зеркало наклонное! Прямо применить `TE` нельзя.

---

## 2. Гениально ленивая идея

Вместо того чтобы выводить сложную формулу наклонного отражения, сделаем так:

```
1. ПЕРЕЙДЁМ в систему координат, где зеркало — это ось x.
2. Там отразим ПРОСТОЙ матрицей TE.
3. ВЕРНЁМСЯ в обычные координаты.
```

Это как с переводом текста: не умеешь читать по-французски — переведи на
русский, пойми, переведи обратно. «Переводчиком» между системами координат
служит матрица, и вот тут выходит на сцену Грам–Шмидт.

---

## 3. Система координат зеркала

У медведя есть два вектора, описывающих его «зеркальную» систему
(первый — вдоль зеркала, второй — куда-то вбок):

```python
bearBasis = np.array([[1, -1],
                      [1.5, 2]])
# по столбцам: b1 = [1, 1.5] (вдоль зеркала), b2 = [-1, 2]
```

Проблема: эти векторы НЕ перпендикулярны и НЕ единичны — «кривой» базис.
С таким переводчиком будут искажения (как переводчик, который привирает).

Решение ты уже знаешь:

```python
E = gsBasis(bearBasis)    # Грам-Шмидт из урока 09!
```

Теперь в столбцах `E` — честные оси:

- `E[:, 0]` — единичный вектор ВДОЛЬ зеркала (направление b1 сохранилось,
  ведь Грам–Шмидт первый вектор только нормализует);
- `E[:, 1]` — единичный вектор ПОПЕРЁК зеркала (перпендикуляр построен
  вычитанием тени).

Ровно то, что нужно: ось x' — зеркало, ось y' — поперёк зеркала.

---

## 4. Матрица-переводчик

Оказывается (примем это как факт с пояснением ниже):

- `E @ вектор` — переводит вектор ИЗ координат зеркала В обычные;
- `E⁻¹ @ вектор` — переводит ИЗ обычных В координаты зеркала
  (`E⁻¹` — обратная матрица, «отмена» действия E).

Почему `E` переводит ИЗ зеркальных В обычные: координаты — это рецепт
«сколько взять каждой оси» (урок 02, раздел 7). Если вектор в зеркальной
системе имеет координаты `[a, b]`, это значит «a раз ось-вдоль-зеркала плюс
b раз ось-поперёк». Умножение `E @ [a, b]` считает именно
`a × E[:, 0] + b × E[:, 1]` — собирает вектор из осей зеркала, выражая его
в обычных числах.

### Подарок от ортонормированности

Обратную матрицу считать хлопотно. Но для ортонормированной матрицы
(а `E` после Грама–Шмидта именно такая!) есть чудо-свойство:

```
E⁻¹ = E.T        — обратная равна транспонированной!
```

Откуда чудо: в уроке 08 (раздел 4) мы видели, что `E.T @ E` = единичная
матрица. А «обратная» по определению и есть «то, что при умножении даёт
единичную». Значит `E.T` и есть обратная. Транспонировать — мгновенно
и без ошибок округления. **Вот зачем Грам–Шмидт нужен на практике:
он делает матрицы, которые тривиально обращать.**

---

## 5. Собираем формулу отражения

План из раздела 2, записанный матрицами (применяются к точке `r`):

```
шаг 1: перевести в координаты зеркала:      E.T @ r
шаг 2: отразить там простой матрицей:       TE @ (E.T @ r)
шаг 3: вернуться в обычные координаты:      E @ (TE @ E.T @ r)
```

Итого отражённая точка: `r_new = E @ TE @ E.T @ r`

**Важно: читай цепочку СПРАВА НАЛЕВО** — к точке `r` сначала применяется
самая правая матрица, потом следующая, как надевание носка и ботинка:
сначала носок (правая матрица), потом ботинок (левая).

Можно склеить три матрицы в одну «машинку наклонного отражения»:

```
T = E @ TE @ E.T
```

и потом отражать любые точки одним умножением: `r_new = T @ r`.

Схема «перевести → сделать простое → перевести обратно» встречается
в линейной алгебре ПОСТОЯННО. С собственными векторами будет она же.

## 6. Весь код целиком

```python
import numpy as np
import numpy.linalg as la

verySmallNumber = 1e-14

def gsBasis(A):                                     # из урока 09
    B = np.array(A, dtype=np.float64)
    for j in range(B.shape[1]):
        for i in range(j):
            B[:, j] = B[:, j] - B[:, j] @ B[:, i] * B[:, i]
        if la.norm(B[:, j]) > verySmallNumber:
            B[:, j] = B[:, j] / la.norm(B[:, j])
        else:
            B[:, j] = np.zeros_like(B[:, j])
    return B


def build_reflection_matrix(bearBasis):
    """Строит матрицу отражения в зеркале, заданном кривым базисом."""
    E = gsBasis(bearBasis)          # 1) выпрямляем базис Грамом-Шмидтом
    TE = np.array([[1, 0],          # 2) простое отражение "в мире зеркала":
                   [0, -1]])        #    вдоль зеркала не трогаем, поперёк - минус
    T = E @ TE @ E.T                # 3) перевод → отражение → перевод обратно
    return T


# --- испытываем ---
bearBasis = np.array([[1, -1],
                      [1.5, 2]], dtype=np.float64)

T = build_reflection_matrix(bearBasis)

r = np.array([1, 2], dtype=np.float64)      # точка, которую отражаем
r_otrazhenie = T @ r
print("точка:", r)
print("отражение:", r_otrazhenie)
```

Разбор новых строк:

- `E @ TE @ E.T` — умножение трёх матриц по очереди (левое `@` применится
  к результату правого). Получается одна матрица 2×2, в которой «зашита»
  вся цепочка перевести-отразить-вернуть.
- `T @ r` — применяем машинку к точке (урок 06: матрица действует на вектор).

---

## 7. Как проверить, что отражение правильное

Отражение обладает свойствами, которые легко проверить кодом:

```python
# 1) Отразить ДВАЖДЫ = вернуться в исходную точку
print(T @ (T @ r))          # должно напечатать исходную [1. 2.]

# 2) Точка НА зеркале отражается В СЕБЯ
#    (вектор вдоль зеркала - это первый столбец E)
E = gsBasis(bearBasis)
na_zerkale = E[:, 0]
print(T @ na_zerkale)       # совпадёт с na_zerkale

# 3) Длина сохраняется (зеркало не растягивает)
print(la.norm(r), la.norm(T @ r))    # одинаковые числа
```

Эти три проверки — «физика зеркала», выраженная математикой. Если все три
проходят — формула верна. Приём «проверяй свойствами» пригодится тебе всю жизнь.

## 8. Мини-задачи

1. Прочитай словами (справа налево), что делает `E @ TE @ E.T @ r`.
2. Возьми `bearBasis = np.array([[1, 0], [1, 1]])` (зеркало вдоль диагонали
   «45 градусов»). Построй T и отрази точку `[1, 0]`. Догадайся ЗАРАНЕЕ,
   куда она попадёт (нарисуй на бумаге зеркало-диагональ и точку!).
3. Что будет, если в `TE` поставить `[[1, 0], [0, 1]]` (единичную матрицу)
   вместо `[[1, 0], [0, -1]]`? Подумай, потом проверь.

---

## Ответы

1. «Переводим точку в координаты зеркала; там отражаем простым переворотом
   второй координаты; переводим результат обратно в обычные координаты».
2. Точка `[1, 0]` отразится в `[0, 1]` — зеркало на диагонали меняет x и y
   местами. Код:

```python
bearBasis = np.array([[1, 0],
                      [1, 1]], dtype=np.float64)
T = build_reflection_matrix(bearBasis)
print(T @ np.array([1., 0.]))     # [0. 1.] (с точностью до 1e-16)
```

3. Получится `T = E @ I @ E.T = E @ E.T` = единичная матрица: перевели
   туда-обратно, ничего не сделав по дороге. Каждая точка останется на месте.
   Хорошая иллюстрация того, что «вся работа» происходит в среднем множителе.
